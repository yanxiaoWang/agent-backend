实现了 AI stream 流式聊天：Redis 短期记忆 + Mem0 长期记忆

# redis（短期）

redis 主要实现短期记忆存储，当前会话的记录，可以设置最多多少条开启压缩，摘要压缩可以通过大模型使用 langchain 中间件，可以设置过期时间 ttl。

# mem0（长期）

mem0 主要做长期记忆，可分层存储：
- 用户层（user）：换会话仍保留——身份、居住地、过敏、持久偏好
- 会话层（session / run_id）：只当前聊天窗口——任务、大纲、进度、临时决策

分层由分类提示词 + structured output 决定是否 `write_user` / `write_session`。

流式链路：
1. Redis 加载短期 history
2. Mem0 search 用户层 + 会话层 → 注入 SystemMessage（不写回 Redis）
3. stream 结束后：过滤 SystemMessage 写回 Redis；分类后可选 add 到 Mem0

环境变量：`MEM0_API_KEY`、可选 `MEM0_TOP_K`
API：`DELETE /ai/memory/:userId/:sessionId/mem0` 清空 Mem0

---

Agent 基本都是用 Redis 做短期记忆，用 PostgreSQL 做历史消息、向量检索。
DeepAgents / summarizationMiddleware 做消息摘要+截断，Redis 做短期记忆存储。
Redis 基本是 Agent 短期记忆存储的最佳方案。

# postgreSQL

一般会把每轮消息存入 PostgreSQL 做历史消息，还能用来基于向量做长期记忆检索（与 Mem0 互补）。
